# Alicia en el País de las Maravillas

## 1. Descripción del proyecto

Este proyecto consiste en una página web interactiva inspirada en Alicia en el País de las Maravillas.

Fue desarrollado con HTML5, CSS3 y JavaScript básico, sin frameworks ni bibliotecas externas.

## 2. Objetivo general

Desarrollar una página web interactiva aplicando formularios HTML, estilos CSS, validaciones, funciones JavaScript y estructuras de control.

## 3. Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server
- Git y GitHub
- GitHub Pages

## 4. Ejercicios desarrollados

### Ejercicio 1: La poción mágica de Alicia

Calcula la altura final de Alicia a partir de su altura inicial y la cantidad de poción utilizada.

Regla matemática:

Altura final = altura inicial - (2 × cantidad de poción).

La altura final se compara con una puerta de 140 centímetros.

### Ejercicio 2: La merienda del Sombrerero Loco

Permite seleccionar una bebida, introducir el nombre del invitado y determinar la cantidad de tazas.

Calcula el subtotal y aplica un descuento del 10 % para compras de 10 tazas o más.

### Ejercicio 3: El desafío de la Reina de Corazones

Analiza los números desde 1 hasta el número introducido.

Clasifica los números pares e impares, calcula sus cantidades y sumas, y determina cuál grupo tiene la suma mayor.

## 7. Casos de prueba
